# 🌷 Pour Elle — متجر إلكتروني مجاني

> *Parce qu'elle compte aussi.*

متجر إلكتروني كامل وسريع، **مجاني 100%** (بدون استضافة مدفوعة ولا اشتراكات)، مصمم للسوق الجزائري:

- 🛍️ صفحة رئيسية، متجر بالفئات والبحث، صفحة لكل منتج، سلة تسوق
- 💵 **الدفع عند الاستلام** مع اختيار الولاية (58 ولاية) والبلدية
- 🚚 حساب سعر التوصيل تلقائياً (منزل / مكتب) + توصيل مجاني فوق مبلغ معيّن
- 📊 الطلبات تصلك في **Google Sheets** و/أو **واتساب**
- 🔐 **لوحة تحكم** لإدارة المنتجات والطلبات (`admin.html`)
- 📱 متجاوب مع الهاتف، باللغة العربية (RTL)

## 🚀 النشر مجاناً على GitHub Pages
1. في المستودع: **Settings ← Pages**
2. Source: **Deploy from a branch** ← اختر الفرع ثم المجلد `/ (root)` ← **Save**
3. بعد دقيقة يصبح متجرك متاحاً على: `https://<username>.github.io/dz/`

(يمكن أيضاً رفع المجلد مجاناً على Netlify أو Cloudflare Pages بالسحب والإفلات.)

## ⚙️ التخصيص
| الملف | ماذا تعدّل |
|---|---|
| `js/config.js` | الهاتف، واتساب، روابط التواصل، رابط لوحة التحكم `apiUrl`، التوصيل المجاني |
| `js/products.js` | المنتجات والفئات والأسعار والصور |
| `js/wilayas.js` | أسعار التوصيل لكل ولاية |
| `assets/` | الشعار `logo.jpg` والبانر `banner.jpg` وصور المنتجات |

**إضافة صور المنتجات:** ضع الصور في `assets/products/` (مثلاً `serum.jpg`) ثم في `products.js` اكتب `image: "assets/products/serum.jpg"`. يفضّل صور مربعة.

## 🔐 لوحة التحكم (المنتجات والطلبات) — مجانية عبر Google Sheets
اللوحة على الرابط: `https://<username>.github.io/dz/admin.html`

**ماذا تقدّم:**
- 🧾 **الطلبات:** إحصائيات (طلبات اليوم، الجديدة، المداخيل)، بحث، تصفية حسب الحالة، تغيير الحالة
  (جديد ← مؤكد ← تم الشحن ← تم التسليم / ملغى / مرتجع)، اتصال أو واتساب بنقرة، حذف، وتصدير Excel (CSV).
- 🛍️ **المنتجات:** إضافة / تعديل / حذف / إخفاء، رفع الصور من الهاتف مباشرة (تُحفظ في Google Drive)، الأسعار والتخفيضات والخيارات والترتيب.
  أي تعديل يظهر في المتجر فوراً دون لمس الكود.

**التركيب (مرة واحدة، 5 دقائق):**
1. أنشئي Google Sheet جديد ← **Extensions ← Apps Script**
2. الصقي محتوى الملف `google-apps-script.gs`، و**غيّري كلمة السر** في السطر `ADMIN_PASSWORD`، ثم احفظي
3. **Deploy ← New deployment ← Web app** — Execute as: *Me*، Who has access: *Anyone* ← وافقي على الصلاحيات
4. انسخي الرابط وضعيه في `js/config.js`:
   ```js
   apiUrl: "https://script.google.com/macros/s/XXXX/exec",
   ```
5. افتحي `admin.html`، ادخلي بكلمة السر، ثم في تبويب المنتجات اضغطي **«استيراد المنتجات الحالية»** لنقل منتجات `products.js` إلى اللوحة.

> بعد أي تعديل على كود Apps Script: **Deploy ← Manage deployments ← Edit ← Version: New version**.
> إذا لم تضعي `apiUrl`، يعمل المتجر من `products.js` وتصل الطلبات عبر واتساب فقط.

## 🧪 التجربة محلياً
افتح `index.html` مباشرة في المتصفح، أو:
```bash
python3 -m http.server 8000
```
